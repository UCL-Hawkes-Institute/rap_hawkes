# 2. Working on the CS HPC Cluster
11th December 2025

Ed and Angie from the UCL CS cluster support team joined us ✨ **in-person** ✨ for this week's session on using the CS HPC cluster. They covered how to:
- manage data storage
- track job usage
- submit array jobs
- and more! 

If you missed out this thrilling opportunity to ask the cluster team questions face-to-face, you can find them at Malet Place, where we're sure they'd be open to helping with any issues you may have (maybe send an email first!).
